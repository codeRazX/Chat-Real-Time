# 🗨️ Real-Time Chat App with Socket.IO

[![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat&logo=node.js&logoColor=white)](https://nodejs.org/)
[![Express](https://img.shields.io/badge/Express-000000?style=flat&logo=express&logoColor=white)](https://expressjs.com/)
[![Socket.IO](https://img.shields.io/badge/Socket.IO-010101?style=flat&logo=socket.io&logoColor=white)](https://socket.io/)

This project is a real-time chat application built with **Node.js**, **Express**, and **Socket.IO**, allowing multiple users to communicate inside dynamic rooms.

---

## 🚀 Features

- ✅ Create and join unique chat rooms
- ✅ Real-time communication via WebSockets
- ✅ Active user counter per room
- ✅ System messages when users enter or leave
- ✅ Automatic removal of empty rooms
- ✅ Simple and user-friendly interface (HTML/CSS/Vanilla JS)

---

## 📦 Technologies Used

- **Node.js** 🟢
- **Express** 🚀
- **Socket.IO** 🔌
- HTML, CSS & JavaScript (Vanilla) 🎨
